
## Write insert-if-short

```text
now write insert-if-short x lst n (S2.b) using my-length and my-map. it puts x at the front of every list whose length is less than n, at every level of nesting, and the top-level list counts too. the length is the original length before inserting. remember () is a list too so it becomes (x) when n > 0. just this function
```
